# Research Assistant Google Doc template

Use `SAM-Research-Assistant-Profile-Template.docx` as the canonical profile template.

1. Upload the DOCX to the shared Google Drive.
2. Open it with Google Docs and save/convert it as a Google Doc.
3. Make one copy inside each Research Assistant's folder and name it `About Me` or `Profile`.
4. Keep the section headings unchanged.
5. Replace the `[[...]]` placeholders with the person's information. Unused placeholder-only fields are ignored by the website parser.
6. Put the person's portrait image and CV PDF in the same folder.

To add an extra website section, add a line such as `SECTION: Outreach and Service` followed by the content. The website will render that content under its own heading.
