# Profile photos

Place one `profile.jpg`, `profile.jpeg`, `profile.png` or `profile.webp` in the matching person's folder. The filename is case-insensitive. Refresh the site; no rebuild is needed. Until then, initials are shown. Full folder-to-person mapping is in the main README.

For a new member, use the exact profile slug as the folder name. If an editor has set an explicit Photo URL on that profile, clear it to use the folder image.
